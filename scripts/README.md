# Skripte

| Skript | Zweck |
|---|---|
| `build_amazon_batch.py` | Eine ganze Amazon-Charge bauen (GTINs, Prüfung, FBA-Kopie, beide Amazon-Dateien) |
| `ean_tools.py` | GTIN prüfen, nächste freie Nummer, Nummern vergeben (Register) |
| `validate_listings.py` | Listing-Tabelle prüfen (`--nur-neu` für Amazon-Chargen) |
| `make_fba_copies.py` | FBA-Kopie aus der FBM-Tabelle |
| `build_channel_batch.py` | Arbeitstabelle für Otto oder eBay aus der FBM-Hauptversion bauen |
| `fill_amazon_home_mirror.py` | Amazon-Vorlage Heim-Spiegel füllen |
| `fill_image_urls.py` | Bild-URLs in die Tabelle eintragen |

Aufruf immer aus dem Repo-Hauptordner mit `python3 scripts/<name>.py`.
