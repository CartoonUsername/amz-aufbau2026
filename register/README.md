# Register

Stammdaten, die alle Kanäle und Skripte gemeinsam nutzen.

- `gtin_register.csv`: alle vergebenen GTINs (GS1-Basisnummer 4255822), Regeln in `../anleitungen/gtin_regeln.md`.
- `amazon_wertezuordnung.csv`: bestätigte Zuordnung einer eigenen Angabe zum Dropdown-Wert der Amazon-Vorlage.
- `amazon_home_mirror_felder.csv`: alle Felder der Amazon-Vorlage HOME_MIRROR mit Pflichtstatus.
